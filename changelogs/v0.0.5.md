# Tidal Terror 0.0.5 — Alpha

- Restore seabed placement for shipwrecks and ruined portals in all province zones, including the Sunken Wastes. Portal foundations connect to sediment, and native template rotation, chunk clipping, loot handling, and saved reloads are preserved.
- Retain province biomes above sea level, preventing original land biomes from allowing villages and grass over excavated ocean.
- Add native regressions for 20 rotated shipwrecks, five ruined portals, foundation support, saved reloads, and village biome eligibility above sea level.
- Add alpha, beta, and release CurseForge channels to the release pipeline. Unspecified channels default to release; 0.0.5 uses alpha for all five loader/version targets.
- Keep GitHub metadata consistent: alpha and beta builds are prereleases and do not replace the stable Latest release; release builds are stable and marked Latest.

Changes apply to future chunk and structure generation after updating. Existing floating structures are not automatically relocated. Deep-world, preset compatibility, and performance limitations documented for 0.0.4 still apply.
