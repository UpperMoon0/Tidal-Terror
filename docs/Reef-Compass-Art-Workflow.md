# Reef Compass generated artwork

Created with the **built-in `image_gen` tool**, not the API/CLI fallback. Original transparent PNGs are local artwork inputs at `docs/assets/reef-compass/generated-dial.png` and `generated-needle.png`; they are excluded from Git. The game assets are `src/main/resources/assets/tidalterror/textures/item/reef_compass_00.png` through `_31.png`, generated by `tools/province/PackReefCompass.java` as 64x64 RGBA frames with nearest-neighbor scaling and a rotating needle. No existing artwork was replaced.

The `docs/assets/reef-compass/compass-pose-0.png` through `compass-pose-3.png` screenshots come from the real Forge client and show native item-model selection after asynchronous server attunement. Four native property bearings and atlas sprites are verified separately from visual inspection.

## Exact dial prompt

Use case: stylized-concept. Asset type: Minecraft inventory item texture, a single square pixel-art sprite. Create the dial/body of a Reef Compass for an underwater coral exploration mod. A round aged brass and dark teal compass with tiny coral-pink accents, pale seafoam tick marks and a deep turquoise glass face, readable and charming like vanilla Minecraft item art. Front-facing orthographic top-down circular dial, centered on a genuinely transparent background, full object inside square canvas with a small transparent margin. Crisp chunky pixel art that reads as a 32 by 32 pixel logical sprite enlarged with nearest-neighbor blocks; restrained palette, sharp pixel edges, no antialiasing, no perspective. IMPORTANT: NO POINTER OR NEEDLE on the dial, leave the center clean dark teal so a rotating separate needle can be layered in the game. No letters, numbers, words, shadows outside the sprite, scenery, grid or watermark. Exactly one dial/body sprite.

## Exact needle prompt

Use case: stylized-concept. Asset type: a separate rotating needle sprite for a Minecraft Reef Compass inventory texture. Exactly one narrow two-ended compass needle, pointing vertically UP, seen flat directly from above. Long coral-pink/red upper triangular point, shorter pale seafoam/ivory lower triangular tail, small brass square pivot exactly at the canvas center. Pixel art with crisp chunky square pixels, restrained colors, readable at a 32x32 logical sprite resolution. Genuinely transparent square background, no compass body/dial/rim, no text, no scenery, no shadows, no black or white backing. Needle occupies only the central 35% of the canvas height and 8% width, with most canvas transparent. Pivot centered at 50% width and 50% height. It will be composited over a separate dial and rotated around its center by the game's resource pipeline.

## Reproduction

Compile and run the Java packer with the two original PNG paths and the assets/tidalterror output root. The original art has its visual dial center lower than the complete pendant canvas; the packer aligns the needle pivot to that visual center. The output models use the vanilla compass angle property and 32 frame thresholds. Native render checks use `tools/province/compass-client.init.gradle` in an independent copy of the passed balanced native fixture world.
