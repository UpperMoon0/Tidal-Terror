# Repository files

Track production sources, game-ready textures/models/data, native test fixtures and checks, build/release tooling, changelogs, licenses and the public README banner.

Ignore worlds, downloaded development mods/shaders, build/cache directories, runtime logs/screenshots, local artwork studies and docs/assets source/reference images. Optional art-export scripts require local source images; they are not part of build or CI. Untracked artwork remains on the developer machine. Deletions remove files from the branch tip after pushing; existing Git history remains intact.

The obsolete 2D Reef Spear icon is removed. Its native model renders held, dropped, framed and in inventory/JEI contexts using the UV atlas.
